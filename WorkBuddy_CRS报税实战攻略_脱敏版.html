1. CRS 到底交换了什么

一句话解释

CRS（共同申报准则） 是全球税务信息自动交换系统。你在香港富途开户的那一刻起，你的账户就在这个系统里。

交换流程

你 → 富途证券（香港）→ 香港税务局 → 中国国家税务总局 → 你所在地税务局

不需要任何人举报，不需要税务局发函调查——数据每年自动交换。

具体交换了哪些数据

根据 CRS 申报标准，富途每年会向香港税务局报送你账户的以下信息：

交换内容说明
姓名、身份证号、地址你的身份信息
账户编号、账户余额年末账户总资产
全年股息收入总额所有股票派发的股息总和
全年利息收入总额账户现金余额产生的利息
资产处置收入总额卖出股票的总成交金额（不是盈利，是总卖出额）
年末持仓市值12月31日你持有股票的总市值

⚠ 注意：CRS 报的是总卖出金额，不是你的盈利。但税务局拿到你的数据后，如果你解释不清买入成本，就可能按总卖出金额核定征税——那就冤大了。

这意味着什么

税务局知道你：

  • ✅ 有哪些境外账户
  • ✅ 每年拿了多少股息
  • ✅ 卖出了多少金额的股票
  • ✅ 年底账户里有多少钱

税务局不一定知道你的买入成本。这就给了你主动申报的空间——你自己算清楚成本，交该交的那部分。

2. 从富途 APP 获取数据

报税需要的原始数据就两类，分别从两个地方获取。

数据一：股息记录 → 月结单 PDF

路径：富途 APP → 底部「交易」→ 右上角「更多」(···) →「月结单」

你会看到按月份的 PDF 列表，像这样：

xxxxx-20220131-xxx.pdf   ← 2022年1月
xxxxx-20220228-xxx.pdf   ← 2022年2月
...
xxxxx-20251231-xxx.pdf   ← 2025年12月

操作：

  1. 选择年份范围（建议从开户开始至今）
  2. 批量下载全部月结单 PDF
  3. 如果有老账户（已停用），也要单独下载老账户的月结单
  4. 把所有 PDF 放到电脑上的一个文件夹里

📌 月结单里有什么：每个月的「资金进出」部分会列出所有股息入账记录，包括股票代码、股数、每股派息金额、预扣税等。

数据二：成交记录 → 历史订单 CSV

这是最关键的数据，因为计算资本利得税需要知道每一笔买入的成本。

路径：富途电脑客户端（注意：手机 APP 导不出完整的成交 CSV）

  1. 在电脑上下载安装 富途牛牛桌面端（futunn.com 官网下载）
  2. 登录后 → 左侧菜单「账户」
  3. 选择账户类型：
    • 保证金综合账户（当前使用的）→ 点「历史」标签
    • 已停用账户（如果之前有老账户）→ 分别选择导出
  4. 设置时间范围：
    • 开始时间：设为账户开通日期，越早越好
    • 结束时间：当天
    • 点击「导出」→ 保存为 CSV
  5. 如果有多个账户（比如老账户迁移到新账户），每个账户都要导出

最终你手上应该有类似这样的文件：

历史-保证金综合账户(XXXX)-日期.csv      ← 当前账户
历史-美股融资融券账户(XXXX)-日期.csv     ← 老账户美股
历史-港股融资融券账户(XXXX)-日期.csv     ← 老账户港股
历史-A股通账户(XXXX)-日期.csv           ← A股通（如有）

📌 CSV 里有什么：每一笔成交的时间、代码、名称、方向（买入/卖出）、数量、价格、币种、费用等。WorkBuddy 就用这些数据做 FIFO 配对。

把 PDF 扔给 WorkBuddy

把下载好的月结单 PDF 全部放到一个文件夹，然后对 WorkBuddy 说：

"这是我的富途月结单，帮我分析一下每年的股息收入和预扣税，我要申报境外投资收入的个税。"

WorkBuddy 会：

  1. 自动扫描所有 PDF
  2. 用 pdfplumber 提取文字
  3. 识别「资金进出」部分的股息记录
  4. 匹配对应的预扣税记录
  5. 按年度汇总

以真实案例为例，WorkBuddy 解析出多年数据：

202212笔~$1,100

每股股息记录都会标注：股票代码、持股数量、每股派息金额。

你会遇到的坑

坑1：月结单格式不统一。 旧版月结单和新版月结单的文字布局不同，WorkBuddy 可能需要调整解析脚本。不用担心，告诉它「格式变了，帮我适配」，它会自动修改。

坑2：预扣税记录不完整。 部分股票（如在开曼群岛注册的公司）不扣美国预扣税。WorkBuddy 会标注这些特殊情况。

坑3：有老账户和新账户。 如果发生过账户迁移，两边的月结单都要解析。告诉 WorkBuddy「老账户迁移到新账户了」，它会把两边的数据合并。

4. 资本利得篇：成交 CSV → WorkBuddy

这是最难但最重要的部分

股息一目了然——收了多少钱就是多少钱。但资本利得不一样：只有卖掉的部分才需要交税，没卖的不用管。

计算逻辑：

资本利得 = 卖出收入 - 买入成本 - 交易费用

这里面有三个关键点：

  1. FIFO（先进先出）：先买的股票先卖掉，成本按买入顺序匹配
  2. 跨账户：如果老账户迁移到新账户，持仓是连续计算的，成本不能断
  3. 股票拆分：某科技股 2024年做了 10:1 拆股，需要调整历史买入记录

把 CSV 扔给 WorkBuddy

把导出的成交 CSV 放到文件夹里，然后对 WorkBuddy 说：

"这是富途导出的历史成交记录，包含老账户和新账户。老账户的持仓迁移到了新账户，帮我用 FIFO 法按年计算资本利得税。"

WorkBuddy 会：

  1. 读取所有 CSV，合并排序
  2. 跳过期权（期权另算）
  3. 处理股票拆分事件
  4. 用 FIFO 法逐笔匹配买入和卖出
  5. 按年度汇总已实现利得

实际效果

以某真实用户为例：

年度已实现利得应纳税（20%）
2022亏损*¥0（亏损不缴税）
2023盈利小几万
2024大幅盈利几万到十几万
2025盈利几万到十几万
合计-/十几万

*注：中国税法规定，境外股票资本利得亏损不能跨年结转抵扣。2022年如有亏损，不能在后续年度抵减。

你会遇到的坑

坑1：老账户数据不完整。 导出 CSV 时记得把时间范围拉到最早（比如2020年甚至更早），否则早年的买入记录缺失，无法匹配卖出。

坑2：股票拆分。 比如某科技巨头在2024年做了 10:1 拆股，如果不处理，会算出巨额错误亏损。告诉 WorkBuddy 股票代码和拆分比例，它会自动处理。

坑3：A股通币种。 A股通账户的交易可能是人民币结算，需要确认汇率。

坑4：第一次导出发现买入不完整。 这是最常见的——因为选了默认时间范围，只导出了最近一两年的。删掉重导，把开始时间拉到最早即可。

5. 算滞纳金：即使现在不交，也知道多少

滞纳金怎么算

滞纳金 = 应补税额 × 0.05% × 滞纳天数
  • 起算日：税款所属年度次年7月1日（申报截止日次日）
  • 年化利率：约 18.25%（是的，相当高）

重点来了

算完滞纳金之后，你对 WorkBuddy 说：

"帮我把含滞纳金和不含滞纳金两个版本都生成 Word 文档和 Markdown 说明。"

WorkBuddy 会生成 4 个文件：

  • 📄 境外投资报税报告_不含滞纳金.docx / .md — 纯税额版
  • 📄 境外投资补税报告_含滞纳金.docx / .md — 含滞纳金版

这样你知道两个数字：你要交多少本金，以及拖到现在每天在涨多少。

6. 为什么实际税额比你想象的少

这里有一个很多人没想明白的点，但算完之后就豁然开朗：

没卖掉的股票，不交税

你账户里那些还在持有的股票，不管涨了多少，只要没卖，就不产生资本利得税。中国税法按「实现制」——成交了才算。

举个例子：你 2020 年买了某科技股，涨了 5 倍，但到现在还没卖。这部分账面盈利 ¥0 税。

总交易金额的 20%？想多了

有人以为税务局会按 CRS 报的「总卖出金额 × 20%」来收税。那是错误的理解。

正确的算法是：

应纳税 =（卖出金额 - 买入成本 - 费用）× 20%

你主动申报买入成本，就是按净利润交税。

绝对收益的 20%？也不对

你今年赚了 100 万，但不是每只股票都卖了。没卖的那些不计入。

一个真实对比（示意）

口径金额如果盲目按20%交
总卖出金额以千万计天价税款
账户总盈利以百万计冤枉多交
实际应纳税十几万✅ 这才是该交的

这就是为什么一定要用真实交易记录算——你不多交一分钱。

核心心法

不是为了逃税，是为了心安。

你把真实数据算一遍，知道自己该交多少。哪怕你现在不打算补缴，你也清楚：

  • 本金是多少
  • 滞纳金每天涨多少
  • 什么时候去交最划算

这个数字一旦算出来了，心里的石头就落地了。因为你会发现：

1. 实际税额远比「总卖出金额 × 20%」小得多——因为你只对实际盈利交税。

2. 实际税额也比「账户总盈利 × 20%」小——因为没卖掉的股票不计入。

3. 算或不算，数据都在那里。算清楚了，主动权在你手里。
