# 价值与反转：四个透镜（只读）

> 代码：`deva/naja/attention/kernel/value_reversal_probe.py` · 上屏：`deva/naja/attention/ui/awakening.py::_render_value_reversal`
> 守卫：`scripts/verify/verify_value_reversal.py`（裸跑=提示档，`--strict`=闸门档，`--exercise-injections`=7 条负向注入）
> 日期：2026-10-19

## 为什么要有它

觉醒卡片原来只回答「系统现在什么状态」与「今天跌得够不够多（超跌三条件）」。
但「跌得多」本身不是买点 —— 用户的问题是对的：**跌得多的东西可能只是变得更便宜，
也可能只是变得更不值钱**。所以需要把「跌」拆成四个互不重叠的透镜：

| 透镜 | 回答 | 数据来源 | 口径 |
|---|---|---|---|
| 价值 | 现价在不在企业真实价值里 | 富途快照 PE(TTM)/PB/BVPS/net_asset/net_profit | 两把尺子（见下） |
| 日线 | 跌到哪了、有没有止跌 | 富途日线 200 天 | 60 日回撤 / MA20 / RSI14 / 5÷20 日均量 |
| 新闻 | 消息面在转向吗 | `~/.naja/focused_news_cache.json` | 词表法极性 + 负面密度环比 |
| 一致预期 | 是不是一边倒了 | 上面三维 + 市场恐慌/广度 | 悲观度 0~100 + 拥挤度 |

## 价值：两把尺子，宁可不说便宜

```
格雷厄姆防守价 = √(22.5 × EPS(TTM) × BVPS)       # 22.5 = 15×PE × 1.5×PB
ROE 合理价     = BVPS × ROE × 15                  # 15 倍 ≈ 6.7% 盈利收益率
倍数           = 现价÷防守价  与  实际PB÷(ROE×15)
```

判定：

* **便宜**：所有可用尺子都 ≤ 0.90
* **贵**：任一尺子 ≥ 1.50
* 其余 → 价值带附近

> ❗**不要合成一个「价值中枢」再算溢价**。格雷厄姆数与 ROE 合理价做几何平均，
> 会造出一个既不防守也不成长的价格，并且给出「高估 289%」这种看着精确、
> 其实不可信的结论。NVDA 就是个例子：格 5.21×、ROE 尺 2.91×，两个数各自可解释。

**ETF 另走一路**：`trust_netAssetValue` 存在时判 ETF，PE/PB 是 `nan`，不能参与估值。
只算对净值的溢折价，±2% 内是申赎套利成本（判「平价」）。
溢折价 >3% 必须提示「净值可能滞后」—— 实测 QQQ 现价 709.8 / NAV 744.5，
真按 4.7% 折价当便宜就是在用隔夜净值交易当天的价格。

## 日线：跌多少不等于跌完了

* `drawdown60`：现价对 60 日最高（≤-20% 深跌 / -10% 中跌 / -3% 小跌）
* `dev20` / `dev60`：均线偏离
* `rsi14`：**简单平均**口径（非 Wilder 平滑），换实现必须同时改注释
* `vol_ratio`：5÷20 日均量。<0.85 = 抛压衰减，>1.10 = 放量

> ❗没有成交量时 `vol_ratio` 必须是 `None`。默认 1.0 会显示成「量能正常」——
> 那是把「没数据」写成「正常」，本项目最典型的一类假信号。

## 新闻：词表法，且只数有极性的条目

新闻池里自带的 `sentiment` 字段 **95% 是默认值 0.5**（实测 319 条里 304 条），
直接求均值永远得到「中性」，等于死面板。所以这里自己打分：

* 词表命中 → `[-1,1]`；**0 = 这条没方向**（不是中性 0.5）
* 只统计 `|score| ≥ 0.15` 的条目，`neg_ratio = neg / scored`
* 相关新闻 <3 条 → `tone="no_signal"`，页面写「样本不足（N 条 / M 条有极性）」
* `neg_trend`：窗口后半段负面密度 − 前半段。**<0 = 利空在钝化**，>0 = 利空在发酵
* ETF 匹配的是「芯片/纳指」这类题材词 → 页面必须标「（题材级）」

## 一致预期：无极生太极

```
悲观度 = 52周位置 0.30 + 60日回撤 0.25 + 新闻负面密度 0.25 + 市场恐慌 0.20
        （按可用维度重归一，缺的维度记 None 并列出）
拥挤度 = |悲观度 − 50| × 2        # 0 = 多空分歧，100 = 一边倒
```

* 悲观度 ≥65 且拥挤度 ≥60 → **极端悲观 · 阴极生阳观察**（direction=+1）
* 悲观度 ≤35 且拥挤度 ≥60 → **极端乐观 · 阳极生阴风险**（direction=−1）
* 悲观/乐观但拥挤度不足 → 「极端但分歧仍大」（这两件事必须分开说）

### 极端 ≠ 反转：必须有同向证据

| 侧 | 触发器（≥2 条才标「值得盯」） |
|---|---|
| 悲观 | RSI 回升 / 量能萎缩 / 利空密度下降 / 广度回升 / 站上 MA20 |
| 乐观 | RSI 走弱 / 放量滞涨 / 利空密度上升 / 广度恶化 / 跌破 MA20 |

> ❗两套触发器必须成对。只写「改善」会让「阳极生阴」永远无法验证，
> 变成一个只能嘴上说的标签。
> ❗`opportunity` 恒为 `False`：这是只读判断，真执行仍要过守望层与 Manas 闸门。
> `watch=True` 只是「值得盯」，不是「可以买」。

## 只读约定

* 不写 NB、不下单、不改 `action_type`、不产出 `size_hint`
* 结果 300s 内存缓存（页面反复刷新不重复打 OpenD），不落盘 → 不会出现
  「文件里的数是昨天的」
* 取不到数据 → `ok=False` + `reason` + 每条标的的 `errors`，页面写「未采集：原因」，
  **不返回空 rows 假装「没有机会」**

## 当前局限（写在这里，别藏）

1. **不含增长调整**：没有可靠的营收/利润增速来源，合理 PE 一律按 15 倍，
   高增长股（NVDA）会被判偏贵。这是口径局限，不是结论。
2. **NAV 可能滞后**：ETF 净值是最近披露值，T+1 很常见。
3. **词表法**：不是语义模型，反讽、反事实、长文本因果都读不出来。
4. **新闻样本薄**：四个关注标的在 72h 窗口内往往只有 1~13 条，多数时候不够下结论。
5. **止跌确认只有日线级**：没有分时/盘口，日内假摔识别不了。
