### 1.2 Step 1：新增 `pe_classifier.py` —— 分类不靠拍脑袋

新模块放在领域层 `deva/naja/structural_growth/pe_classifier.py`（纯函数，好测）。

输出 `ValuationRegime`。判据经 **2026-10-20 用 33 只真实标的校准**，分**强 / 弱**两级加权（强 2 分、弱 1 分），
且**每侧必须至少命中 1 条强证据**才够格定类：

| | 判据 | 权重 | 实测命中率 |
|---|---|---|---|
| **C1** | 净利同比的**对数尺度**标准差 > 3.5 | 强 2 | 55% |
| **C2** | 负增长期数占比 ≥ 1/3，**或**出现过同比 < −100%（由盈转亏） | 强 2 | 42% |
| **C3** | 毛利率极差 > 10pp（周期反转） | 弱 1 | 19% |
| C4 | 毛利率与价格因子相关 > 0.5 | 弱 1 | 0%（需 `price_series`，暂无源） |
| C5 | 自身 PE 历史中位 < 20 | 弱 1 | 0%（需 `pe_history`，暂无源） |
| **S1** | 最近 3 期净利同比**持续为正** | 强 2 | 30% |
| **S2** | 毛利率单调扩张 ∈ [1pp, 20pp] | 弱 1 | 30% |
| **S3** | 经营现金流/净利 ≥ 1.2 | 弱 1 | 52% |

| 分类 | 含义 |
|---|---|
| `CYCLICAL` 周期 | 利润均值回归，**不配成长估值** |
| `STRUCTURAL_GROWTH` 结构性成长 | 利润跃迁可持续，可切换成长估值 |
| `BASE` 稳态 | 两侧都不够格，或打平（**不猜**） |
| `UNKNOWN` | 有效数据 < 4 期 —— ❗**必须显式存在**，`None ≠ BASE` |

校准期实测分布：**周期 17 / 结构性成长 7 / 稳态 8 / 未分类 1**，24 只给出可用结论。

#### 校准改了什么，以及为什么（都踩出来过）

1. **C1 改用对数尺度标准差**。净利同比是比率、分布重尾：WDC 有一期 +3242%，
   原始 sd = 1393.6 —— 一个数支配全样本尺度，阈值怎么切都区分不开
   （25pp→76% 命中，80pp→还有 55%）。改 `sign(x)·ln(1+|x|)` 后：
   ISRG（稳定成长）原始 sd 94.5 排到 LRCX（23.7）前面，**结论是反的**；
   对数尺度下 ISRG 0.93、LRCX 2.86，排序才对。
2. **C2 从「出现过负增长」改成「占比 ≥1/3」**。原判据 33 只里命中 **29 只（88%）** ——
   那是必然事件不是证据（数据覆盖 2022-23 下行，谁都有一年负增长）。
3. **C3 阈值 20pp→10pp**。原阈值只抓到 2/33（6%），太钝。
4. **S3 阈值 0.8→1.2**。0.8 有 76% 命中 —— 周期股在景气顶部现金流同样漂亮，
   这不是成长的证据。
5. **判据加权，且要求强证据**。等权计数时 CRM（波动全池第 8）被判**稳态**、
   LRCX/KLAC/AMAT（半导体设备周期股）被判**结构性成长** —— 靠的都是 S2+S3
   两条**在周期上行期同样成立**的弱证据。弱证据不该有扳倒强证据的票数。
6. **亏损公司的负增长降级为弱证据**。对亏损公司，"同比为负"衡量的是亏损扩大
   速度而非周期波动：SNOW 4 期同比全负，按占比 100% 会被判成周期股。
   降级后 SNOW 落稳态，而 INTC（同样亏损但波动 4.40）靠 C1 仍正确判周期。
7. **confidence = 净优势 / 理想满分**，同时反映「赢了多少」「证据绝对量」
   「数据完整度」三件事。改之前 CRM（反侧有 2 分强证据）和 ENPH（只有 1 条
   证据）**都显示 1.00**；改完全池只有 WDC 是 1.00。

> ❗分类输出必须带 `confidence` + `evidence[]`（哪几条命中、具体数值），**不许只给一个标签**。理由同 `PanicAnalyzer`：只给结论不给依据，后面没人能复核。
> ❗不许默认 `BASE` —— 数据不足必须返回 `UNKNOWN`，否则「没数据」会被静默读成「稳态」，这正是本项目反复踩的坑。
> ❗`sample_sufficiency`（期数/8）要一起上屏：**当前全池只有 4 期年度财报，充分度恒为 0.50**。
> 4 期看不出一个完整周期，所以所有结论都是**保守默认，不是精确结论**。

### 1.4 Step 3：目标 PE 区间 —— 重定价的"尺子"（已落地 → `pe_bands.py`）

> ❗**PE 带不许写死成常量表**。理由（本项目的实锤教训）：OpenRouter 那套写死周期粒度的代码改版后**静默失效 160 天**。写死的估值带同样会。

#### ❗❗第一版实测就废了 —— 「按分类分组造尺子」是错的

原设计：周期带 = 池子里 `CYCLICAL` 类票的 PE 分布，结构性带 = `STRUCTURAL_GROWTH` 类票的 PE 分布。听起来最贴语义，跑出来直接废掉：

```
带[周期 26–65 / 结构性 37–65]     ← 两条带几乎完全重叠
priced_in = −2.35 / 24.53 / 59.80 ← 全是荒谬值
15/36 只票「尺子不可用」
```

两个原因叠加：
1. **分类带保守偏差**（只有 4 期年度财报，2022-23 半导体下行让「出现过负增长」普遍命中）→ AMD(174x) / TSLA(306x) 都被判成周期股 → 周期组的 PE 分布比结构性组还贵。
2. 更根本：**用今天的横截面定义"结构性该给多少"**。牛市里所有票都贵，这把尺子测不出"重估空间"，只能测出"谁更贵"。

#### 现在的做法：全池共享的分位尺子

不看分类，直接看 PE 落在**同类池 PE 分布**的哪一段（全池一把尺子，被评估的票自己排除在外）：

| 带 | 分位 | 实测值（2026-10-20，样本 28） |
|---|---|---|
| 周期带 | P15–P40 | 25–37x |
| 基准带 | P40–P65 | 37–59x |
| 结构性带 | P65–P90 | 59–176x |

三个好处：
1. **永远不会反转** —— 分位数天然有序，第一版那种「尺子自相矛盾」在结构上不可能发生。
2. **全池共享**，不同票的 `priced_in` 可以横向比较（第一版每只票按所属行业量，量出来的数互相不可比）。
3. 分类结果不参与造尺子，只参与**判读** —— 各司其职，不会互相污染。

> ❗**这是相对尺子，不是绝对估值锚点**。它回答「市场把它当周期还是当成长在定价」，不回答「它值多少钱」。池子整体高估时，这把尺子测不出高估 —— 这句话已写进页面。

## 2. Part 2：结构性行情来了吗 / price in 了吗 / 还有没有买点

### 2.1 核心新增指标一：`priced_in_ratio`（市场已经定价了多少）

```
priced_in_ratio = (PE_now − 周期锚) / (结构性锚 − 周期锚)
```

❗**锚点取两条带的下沿，不是中值**。实测教训：结构性带上沿被 TSLA(306x) / PLTR(202x) / AMD(175x) 顶到 176x，中值 117x。拿中值当上行目标算出 NVDA 上行 **+256%**、MSFT +271%、SMCI **+661%** —— 那是把「池子里最贵那一档」当成目标价，不是重估空间。改用下沿后 NVDA +57%、上行读数全部落在合理区间。

| 区间 | 判读 |
|---|---|
| < 0.3 | 市场仍按**周期**定价 → 认知差最大，但也可能市场是对的 |
| 0.3 ~ 0.7 | 部分 price in |
| > 0.7 | 基本 price in，剩下的**只能靠业绩兑现**，不是靠重估 |

> ❗**必须和分类交叉读，这是这块设计的灵魂**：
> - 周期股 + `priced_in_ratio` 高 → **不是机会，是陷阱**（它的尺子本来就是周期带，冲进结构性带叫泡沫）
> - 成长股 + `priced_in_ratio` 低 → **才是机会**（基本面已变，市场还没换尺子）
> - 现在的代码完全没有这个交叉，所以"预期差 +5%"到底是机会还是陷阱，答不了。

### 2.2 核心新增指标二：`asymmetry`（不对称比）—— 我建议用它替代"能不能买"

用户问"还有没有买入机会"，我更愿意把它翻译成一个可计算的量：

> **不是问"能不能买"，而是问：如果结构性成立我赚多少；如果证伪我亏多少。**

```
asymmetry = 上行空间 / 下行空间
          = (结构性锚 − PE_now) / (PE_now − 周期锚)
```

❗两种情况下返回 `None`，都不许用 0 或 inf 凑数：
1. 分母 ≤ 0（已跌破周期锚）—— 不是"无穷好的机会"，是**价值陷阱信号**。
2. 下行空间 < 15% —— 分母趋零会把比值顶到几十上百。实测 GOOGL：PE 25.98 几乎贴着周期锚，下行只剩 3.9% → 比值 **32**，纯数学假象。

- `> 2`：赔率合适，值得下手
- `1 ~ 2`：鸡肋
- `< 1`：赢了赚一点、输了亏很多 → **直接否掉**

> ❗**`PE_now ≤ PE_cyclical_mid` 时分母 ≤ 0**：必须返回 `None` 并标注「已跌破周期带，需人工判断（可能是价值陷阱）」。
> **绝不能返回 `inf` 或 `999`** —— 那会让"最危险的票"排在最前面。

### 2.3 核心新增指标三：`entry_window` —— 状态机 × 定价进度 的九宫格

把已有的 S0–S4 状态机（`valuation_state.py`，现在只管基本面、**完全没接价格**）与 `priced_in_ratio` 交叉成 3×3：

|  | priced_in < 0.3 | 0.3 ~ 0.7 | > 0.7 |
|---|---|---|---|
| **S0/S1**（早期） | ★ 最佳赔率区：基本面刚起、市场没定价；胜率最差，仓位要小 | 正常建仓区 | 故事先行、基本面没跟上 → 警惕 |
| **S2**（瓶颈验证） | 认知差窗口 | ★ 平衡点：有证据、未充分定价 | 需要业绩加速兑现才安全 |
| **S3/S4**（利润兑现） | 少见的错杀，重点核查数据 | 趋势跟随，别当重估 | ⚠ **业绩兑现即出货区**：利润已兑现且已定价 |

> ❗九宫格**每格都必须有文案**，不许留空白格 —— 空白格在 UI 上就是黑屏，是"合法的空"。

## 5. 风险与取舍

- **东财美股覆盖不全**（这是真实风险，不是假设）。方案里已要求：取不到必须 `None` + 原因，UI 如实呈现，不接受"用行业均值补"。
- **自算 PE 序列依赖日 K + EPS 口径**，A 股累计口径/美股单季口径必须分开处理（见 §1.1 的 ⚠️）。
- **`asymmetry` 是估值维度，不是放行信号**。它和 `panic_probe` 一样 —— **只进门理由，不参与闸门**，禁止拿它去放松 Manas 阈值。
- 不改 `TransitionRules` 的阈值语义，只增加价格侧的派生字段，状态机本身保持纯基本面。

### 7.2 ❗两把"看起来对"的尺子，跑真实数据就废了

**① 按「同类分类」分组算 PE 分布 → 两条带几乎完全重叠**

```
带[周期 26-65 / 结构性 37-65]   pi = -2.35 / 24.53 / 59.80   ❗15/36 只票「尺子不可用」
```

根因是设计错了：分类器带保守偏差（只有 4 期年度财报 + 2022-23 半导体下行这轮），
AMD(174x)/TSLA(306x) 都被判成周期股 → 周期组的 PE 分布被拉到 26-65x，比"结构性组"还贵。
**用今天的横截面去定义"结构性该给多少"，尺子就没有区分度了。**

改成**全池共享的分位尺子**（不看分类标签）：把全池 PE 排序取分位（低 15-40% = 周期、
40-65% = 基准、65-90% = 结构性），并额外吐三个数：`discrimination`（结构/周期上沿之比，
< 1.5 说明尺子没有区分度）、`composition`（参与每一档的都是谁）、`excluded`（谁被剔了、为什么）。

**② 上行锚点取"结构性带中值" → 上行 +256% / +661% 这种荒谬值**

因为结构性带的中值被 TSLA(306)/PLTR(202)/AMD(174) 的长尾拉到 117x ——
**把"池子里最贵那一档"当目标价，算出来的不是重估空间**。锚点改成"**进入结构性定价的门槛**"
（`structural.low`）：过了门槛就算"已按结构性定价"，不必假设它能涨到最贵。
同时加了下行护栏：下行空间 < 15% 时不许报不对称比（分母趋零会把比值顶到几十上百）。

### 7.4 ❗财报抓取的三次静默失效（都是"字面上看不出来"的那一类）

| 现象 | 真因 | 修法 |
|---|---|---|
| TSM / ASML 一直「分类未定」 | 外国发行人以 **20-F** 报送，命名空间是 **`ifrs-full`** 不在 `us-gaap` 里 → 一期都读不到 | 多命名空间合并视图（`us-gaap` 优先），并补 IFRS 标签别名 |
| ASML / NVO / SAP 仍然 0 期 | 它们报 **EUR / DKK**，`_extract_annual` 只认 `units["USD"]` | 无 USD 时取 FY 行数最多的币种，并记录 `currency`（绝对值不可跨币种比，但同比/毛利率/现金流比都是无量纲的） |
| SAP 只剩 1 期 | 「按最新年份挑标签」的规则被一个"只有 2017 一年"的杂标签顶掉 | 排序键改成 **`(期数, 最新年份)`** |
| CRWD 判「无年度营收标签」 | 它报的是 `RevenueFromContractWithCustomer**Including**AssessedTax`，我们只认 Excluding | 补候选标签 |

❗还要区分 **「这家没有财报」(empty)** 和 **「我们没取到」(error)** —— 两者都是空列表。
不分开的话用户看到的就是一句含糊的「分类未定」，分不清该等还是该排除。
现在 `fetch_detail()` 返回 `(data, status, reason)`，编排层按 status 给不同文案。

### 7.5 判据校准要点（详见当日日志）

- 波动度量从**原始标准差**改成**对数尺度标准差**（`sign(x)·ln(1+|x|)`）：同比是比率、重尾，
  WDC 一期 +3242% 让原始 sd=1393.6 支配全样本。原口径下 ISRG(94.5) 比 LRCX(23.7) 高 4 倍 —— **结论是反的**。
- 「出现过负增长」原命中率 88%（必然事件，不是证据）→ 改成「占比 ≥1/3 或最低 <−100%」，且**亏损公司降级为弱证据**。
- 等权计数 → **强 2 / 弱 1** 加权，且**每侧至少一条强证据**（❗门槛要数"条数"不能用"分数"，`score>=2` 会被两条弱证据凑出来）。
- confidence = **净优势 / 理想满分**（反侧证据越强越扣分；数据不全也扣分）。
