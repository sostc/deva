# 注意力价值观系统显式化计划

## 核心目标

将"Query = 价值观"这一核心理念显式化，在QKV页面展示：
1. 当前系统的价值观状态（关注什么、看重什么）
2. 价值观如何影响注意力计算
3. 通过反馈让价值观不断进化优化

**核心理念：**
> 什么样的价值观，遇到同样的事件，会计算出不同的价值。
> - 追涨杀跌的价值观 → 关注趋势变化 → 趋势型盈利
> - 流动性驱动的价值观 → 关注资金流向 → 流动性型盈利
> - 价值投资的价值观 → 关注均值回归 → 价值型盈利

## 一、现有系统能力分析

### 1.1 注意力系统架构

```
数据源 → AttentionKernel → AttentionOrchestrator → 策略执行
              ↓
           QueryState（当前只有市场状态、风险偏好）
              ↓
           MultiHeadAttention（market/news/flow/meta四个头）
              ↓
           Memory（事件记忆 + 时间衰减）
```

### 1.2 现有策略（已实现价值观雏形）

| 策略 | 类型 | 价值观特征 |
|------|------|-----------|
| `momentum_tracker` | 趋势追踪 | 追涨杀跌，顺势而为 |
| `anomaly_sniper` | 异常狙击 | 发现异常，人弃我取 |
| `smart_money_detector` | 聪明钱 | 跟随主力资金流 |
| `sector_hunter` | 板块猎手 | 板块轮动，趋势动量 |
| `global_sentinel` | 全局哨兵 | 风控第一，均值回归 |

### 1.3 现有反馈系统

- `SignalTuner`: 监控信号产生和盈亏反馈，自动调整参数
- `FeedbackReportGenerator`: 实验模式反馈报告
- `AttentionTracker`: 跟踪注意力信号的价格变化

### 1.4 现有QKV页面

- 展示Query（市场状态、风险偏好、注意力焦点）
- 展示Key（事件列表：价格、成交量、Alpha）

## 二、系统缺陷与改进方向

### 2.1 当前缺陷

1. **Query缺乏价值观显式表达**：只有市场状态和风险偏好，没有价值观配置
2. **策略与价值观绑定不清晰**：策略产生信号，但不清楚背后的价值观逻辑
3. **反馈学习分散**：SignalTuner学习参数，但不学习价值观本身
4. **QKV页面缺少价值观视角**：只有技术数据，没有价值观解释

### 2.2 改进方向

| 维度 | 当前 | 改进后 |
|------|------|--------|
| Query | 市场状态 + 风险偏好 | + 价值观配置 + 决策理由 |
| Key | 事件特征 | + 价值观匹配度 |
| Value | Alpha + Confidence | + 价值观归因 |
| 策略 | 独立运行 | + 价值观标签 |
| 反馈 | 参数调整 | + 价值观学习 |
| QKV页面 | 数据展示 | + 价值观可视化 |

## 三、价值观系统设计

### 3.1 价值观类型定义

| 类型 | ID | 描述 | 核心原则 | 适用市场 |
|------|-----|------|----------|----------|
| 趋势型 | `trend` | 追涨杀跌，顺势而为 | "趋势是你的朋友" | 趋势明确 |
| 逆势型 | `contrarian` | 人弃我取，分歧买入 | "别人恐惧我贪婪" | 极端行情 |
| 价值型 | `value` | 均值回归，价格终究合理 | "价格围绕价值波动" | 震荡市场 |
| 动量型 | `momentum` | 强者恒强，弱者恒弱 | "趋势延续直到反转" | 趋势中期 |
| 流动性型 | `liquidity` | 资金流向，价格之因 | "钱去哪里，价去哪里" | 流动性驱动 |

### 3.2 价值观权重配置

```python
@dataclass
class ValueWeights:
    """价值观权重 - 决定'关注什么'"""
    price_sensitivity: float = 0.5      # 对价格变化的敏感度
    volume_sensitivity: float = 0.5     # 对成交量异常的敏感度
    sentiment_weight: float = 0.3       # 对市场情绪的关注度
    liquidity_weight: float = 0.4       # 对流动性的关注度
    fundamentals_weight: float = 0.3    # 对基本面的关注度

@dataclass
class ValuePreferences:
    """价值观偏好 - 决定'怎么想'"""
    risk_preference: float = 0.5        # 0=极度保守, 1=极度激进
    time_horizon: float = 0.5          # 0=短期交易, 1=长期持有
    concentration: float = 0.5         # 0=分散投资, 1=集中持仓
```

### 3.3 价值观与策略的映射

```
价值观 → 策略选择 → 信号产生

trend + momentum_tracker → 趋势追踪信号
contrarian + anomaly_sniper → 逆向买入信号
liquidity + smart_money_detector → 资金流向信号
value + global_sentinel → 均值回归信号
```

### 阶段三：价值观影响计算（1-2天）

#### 3.1 修改AttentionKernel.process()

**文件**: `deva/naja/attention/kernel/kernel.py`

```python
def process(self, Q, raw_events):
    if not raw_events:
        return {"alpha": 0, "risk": 0, "confidence": 0}

    # 1. 获取当前价值观权重
    value_weights = self._get_value_weights(Q)

    # 2. 用价值观权重调整事件编码
    events = []
    for e in raw_events:
        e.key = self.encoder.encode_key(e)

        # 【核心改动】用价值观调整value编码
        e.value = self.encoder.encode_value_with_values(e, value_weights)

        # 【新增】计算事件与价值观的匹配度
        alignment = self._calculate_value_alignment(e, Q)
        e.value["value_alignment"] = alignment

        # 【新增】生成关注理由
        e.value["focus_reason"] = self._generate_focus_reason(e, Q)

        events.append(e)

    # 3. 多头注意力计算
    result = self.multi_head.compute(Q, events)

    # 4. 【新增】生成决策解释
    result['value_explanation'] = self._generate_value_explanation(Q, events, result)

    # 5. 更新记忆（包含价值观信息）
    for e in events:
        self.memory.update(e, result["confidence"])

    return result

def _calculate_value_alignment(self, event, Q) -> float:
    """计算事件与当前价值观的匹配度 (0-1)"""
    active_type = Q.active_value_type
    weights = Q.active_weights

    # 根据价值观类型计算匹配度
    if active_type == "trend":
        # 趋势型：关注价格变化和动量
        price_score = min(abs(event.features.get("price_change", 0)) / 5.0, 1.0)
        momentum_score = event.features.get("momentum", 0.5)
        return (price_score * 0.6 + momentum_score * 0.4)

    elif active_type == "liquidity":
        # 流动性型：关注成交量变化
        volume_score = min(event.features.get("volume_spike", 1) / 3.0, 1.0)
        return volume_score

    # ... 其他价值观类型

    return 0.5  # 默认中性

def _generate_focus_reason(self, event, Q) -> str:
    """生成为什么关注的理由"""
    active_type = Q.active_value_type
    reasons = {
        "trend": f"符合趋势追踪原则，价格变化{event.features.get('price_change', 0):+.2f}%",
        "liquidity": f"成交量放大{event.features.get('volume_spike', 1):.1f}倍，流动性异常",
        # ...
    }
    return reasons.get(active_type, "符合当前价值观")
```

#### 3.2 修改AttentionHead计算

**文件**: `deva/naja/attention/kernel/head.py`

```python
def _aggregate(self, weights, values):
    """加权求和 - 加入价值观匹配度"""
    result = {"alpha": 0, "risk": 0, "confidence": 0, "value_breakdown": {}}
    for w, v in zip(weights, values):
        if not isinstance(v, dict):
            continue

        # 基础加权
        result["alpha"] += w * v.get("alpha", 0)
        result["risk"] += w * v.get("risk", 0)
        result["confidence"] += w * v.get("confidence", 0)

        # 【新增】价值观匹配度加权
        alignment = v.get("value_alignment", 0.5)
        result["alpha"] *= (0.5 + alignment * 0.5)  # 匹配度高则放大alpha

        # 【新增】记录价值观贡献分解
        if "value_type" in v:
            vt = v["value_type"]
            if vt not in result["value_breakdown"]:
                result["value_breakdown"][vt] = 0
            result["value_breakdown"][vt] += w * v.get("alpha", 0)

    return result
```

## 七、核心哲学阐释

> **境随心转，执处成真**
>
> 在注意力系统中：
> - **Query（心）** = 价值观
>   - 决定"关注什么"
>   - 决定"看重什么"
>   - 决定"怎么想"
>
> - **Key（事件）** = 世界本来的样子
>   - 价格变化、成交量变化、基本面数据
>   - 但同样的数据，被不同的价值观"看到"不同的机会
>
> - **Value（价值）** = 价值观计算的结果
>   - 价值观决定如何解读事件
>   - 价值观决定如何加权聚合
>   - 价值观决定什么是"有价值"
>
> - **反馈闭环**：
>   - 价值观产生行动 → 行动产生结果 → 结果反馈强化/修正价值观
>   - 这不是算法，是"价值生成系统"

## 八、与传统量化系统的根本区别

| 维度 | 传统量化系统 | 注意力价值观系统 |
|------|-------------|-----------------|
| **核心驱动** | 价格变化 | 价值观判断 |
| **关注点** | 涨跌幅、动量 | 符合价值观的事件 |
| **盈利逻辑** | 追涨杀跌 | 价值观匹配赚钱 |
| **反馈机制** | 参数优化 | 价值观进化 |
| **系统目标** | 跟踪价格赚钱 | 发现价值创造收益 |

**真正的区别**：
- 不是盯着价格变化去赚钱
- 而是分析数据、发现问题、提供价值
- 是真正给市场创造价值的系统
